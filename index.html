OSM Web Driver

1 / 3

Three.js · Rapier physics · Python · OpenStreetMap

OSM Web Driver turns real places into a driving game that runs in the browser. A Python tile server bakes OpenStreetMap extracts, Overture building footprints and elevation models into tiles, and the Three.js client streams them in around the car and builds road meshes, terrain, buildings and forests on the fly. New geometry loads outside a fade band and dithers in instead of popping up, and distant terrain is drawn as clipmap level-of-detail rings that reach about 100 km. The car runs on Rapier rigid-body physics, traffic uses kinematic bodies the player can collide with, and multiplayer syncs positions through a small HTTP relay. The screenshots show a lakeside road, the view from the hill above Huskvarna next to the real map, and Katarinavägen in Stockholm.

Spearmed

1 / 3

TCCC · Offline first · Medic in control

Spearmed is a documentation and decision-support tool for field medics, built on NATO's Tactical Combat Casualty Care (TCCC) guidelines. It rests on a few principles. It has to work where medics work, so it runs fully offline on the device and keeps patient data encrypted. The medic stays in charge: the tool suggests diagnoses, questions to ask and next steps, but every change to a casualty card is approved by the medic, whether it was typed, spoken or proposed in the chat. And advice has to be traceable, so care guides are built from a trusted medical library in English and Swedish and every source is cited. In practice, medics register and triage casualties on a digital TCCC card, follow how each casualty is doing over time with safety warnings along the way, and can ask for help with a diagnosis or a care guide when they need it.

Homeserver

Docker · systemd · Tailscale · Immich · Navidrome · Syncthing

A workstation at home now does the job of most Google services. Photos moved from Google Photos to Immich, imported from a Takeout archive with the original dates, locations and albums kept, and the GPU runs the machine-learning models for face and object search. Music lives in a Navidrome library instead of a streaming service, and files sync between devices with Syncthing instead of Google Drive. Nothing is exposed to the internet: every service is reachable only over a private Tailscale network (WireGuard).

The same machine is where projects get built and tested. Each service runs as a Docker container or a systemd user unit, all set up by one idempotent script that can be re-run after a reinstall, and a start page called Hubworld shows the weather and health checks for every service. New builds of OSM Web Driver and Spearmed are hosted on the private network too, so they can be tried on a phone right away.
